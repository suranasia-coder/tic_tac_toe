# Tic Tac Toe Game

A simple graphical Tic Tac Toe game built with Python and Tkinter.

## Description
This is a classic Tic Tac Toe game where two players take turns marking spaces in a 3x3 grid. The player who succeeds in placing three of their marks in a horizontal, vertical, or diagonal row wins the game.

## Features
- Graphical user interface using Tkinter
- Two-player gameplay
- Win detection and highlighting
- Player turn indicator

## Requirements
- Python 3.x
- Tkinter (included with most Python installations)

## How to Run
Run the script with Python:
```
python tic_tac_toe.py
```

## Gameplay
- Player X starts first
- Click on an empty cell to place your mark
- The game ends when one player wins or the board is full (tie)
